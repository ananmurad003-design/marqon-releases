# ثراء 👑 — مستشارك المالي

تطبيق أندرويد يقسّم كل دخل على صناديق حسب أفكار كتب الثراء، ويتابع مصاريفك وديونك وأهدافك واستثماراتك.

## تنزيل الـ APK
1. افتح تبويب **Actions** بالمستودع ← **Tharaa Android APK** ← آخر تشغيل ناجح ✅
2. من **Artifacts** نزّل `Tharaa-1.0.N` (ملف zip فيه الـ APK)
3. فك الضغط وثبّت الـ APK (اسمح بالتثبيت من مصادر غير معروفة)

## مفتاح التوقيع (مهم للتحديثات)
بدون مفتاح ثابت، كل بناء بيتوقّع بمفتاح مؤقت مختلف، فالتحديث بيحتاج حذف النسخة القديمة (صدّر نسخة احتياطية قبلها).
لتثبيت التحديثات فوق بعض، أضف هالـ Secrets بالمستودع (Settings ← Secrets and variables ← Actions):
`THARAA_KEYSTORE_B64` (ملف keystore بصيغة base64)، `THARAA_STORE_PASSWORD`، `THARAA_KEY_ALIAS`، `THARAA_KEY_PASSWORD`.

## الفكرة
- **4 مراحل** (التأسيس ← التحرر من الديون ← درع الأمان ← بناء الثروة) والنسب بتتغير تلقائياً مع تقدّمك.
- **ادفع لنفسك أولاً**: 10% على الأقل للاستثمار من كل دخل.
- **سقوف ذكية**: الطوارئ بتوقف عند 4 شهور، والديون عند المبلغ المتبقي، والزيادة بتروح للاستثمار.
- **قاعدة الدخل الزائد**: لما تدخل فوق متوسطك، نص زيادة المصروف بيروح للاستثمار.
- **ترحيل نهاية الشهر**: المتبقي من الأساسيات ← الاستثمار، والمتبقي من المصروف ← الطوارئ.
- **الديون**: كرة الثلج أو الأعلى فائدة أولاً. **الأهداف**: بالترتيب مع عداد تقدم.
- **الاستثمار**: أسعار حية (Yahoo Finance) وربح/خسارة المحفظة بالشيكل.
- **نسخ احتياطي** تلقائي يومي لملف على Google Drive، وتصدير/استرجاع يدوي.

## البناء محلياً
```
cd tharaa && ./gradlew assembleRelease
```
